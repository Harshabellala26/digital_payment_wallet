# digital_payment_wallet

A secure and modern digital payment wallet built using the MERN stack that enables users to manage their finances through a seamless web interface. The application provides secure authentication, wallet management, and digital payment features with a focus on performance, scalability, and user experience.

🚀 Key Features
🔐 Secure user authentication using JWT.
👤 User registration, login, and profile management.
💰 Digital wallet with balance tracking.
💸 Send and receive money between users.
📜 Transaction history with real-time balance updates.
⚡ Responsive and intuitive user interface.
🛠️ Tech Stack
Frontend: React.js, HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JSON Web Tokens (JWT)
API Testing: Postman
🎯 Objective

To develop a secure and scalable digital wallet application that simplifies online payments and money transfers while demonstrating full-stack web development, authentication, RESTful API integration, and database management using the MERN stack.
